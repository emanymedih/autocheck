# Brand icons

The initial local brand icon set is sourced from the Simple Icons project (CC0 1.0). Brand names and logos remain trademarks of their respective owners and are used only to identify vehicle makes in the AutoCheck catalog.

Local icons currently included:
- Audi
- BMW
- Cadillac
- Chevrolet

For supported brands not yet stored locally, the homepage falls back to the Simple Icons CDN. If an icon is unavailable, the interface shows a neutral brand monogram instead of a broken image.

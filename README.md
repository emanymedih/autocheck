# Авточек

Каркас стартовой страницы сервиса проверки истории автомобиля по VIN.

Текущий MVP:
- один главный сценарий — ввод VIN;
- Китай как первый активный рынок;
- пользователь не выбирает Che300, ChaBoShi и другие внутренние источники;
- оплата пока не подключена;
- автоматический опрос источников пока не реализован;
- адаптивная стартовая страница;
- базовая клиентская проверка VIN.

Следующие этапы:
1. Подключить backend для VIN.
2. Добавить предварительное определение автомобиля.
3. Реализовать экран подготовки отчёта.
4. Подключить оплату.
5. Подключить внутренний orchestrator источников.

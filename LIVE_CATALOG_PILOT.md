# Авточек — первый живой автомобиль в Catalog Collector

Дата пилота: 2026-08-19.

## Что подключено

Для первого сквозного теста выбрана публично доступная карточка реально выставленного автомобиля:

- Audi A3;
- модельный год: 2024;
- версия: A3L Limousine 35 TFSI;
- цена: 158 800 CNY;
- пробег: 7 000 км;
- первая регистрация: 12.2023;
- коробка: автомат;
- двигатель: 1.4L;
- переоформлений: 0;
- 25 фотографий;
- статус на момент проверки: объявление активно и содержит действие запроса цены.

Внутренние source identifiers сохранены только в `collector/data/catalog.json`. Публичная DTO-модель их не содержит.

## Реализованный контур

`одна разрешённая публичная URL-карточка`
→ `Che168PilotProvider`
→ `raw listing`
→ `Normalizer`
→ `vehicle_id`
→ `JsonCatalogStore`
→ `/api/vehicles`
→ `cars.html`
→ `vehicle.html`.

Добавлен CLI:

```bash
cd collector
npm install
npm run import:che168-pilot -- --url "https://s.che168.com/dealer/123615/58736709.html?pvareaid=106453"
npm start
```

Адаптер работает с одной detail-URL за запуск. Массовый обход дилерских страниц в этот pilot не заложен.

## Что извлекает pilot adapter

- `dealer_id` и `listing_id` из URL;
- марку и модель;
- модельный год;
- цену;
- пробег;
- первую регистрацию;
- коробку;
- объём двигателя;
- регион регистрации;
- количество переоформлений;
- экологический стандарт;
- текст объявления;
- фотографии;
- признаки доступности карточки.

Технические поля источника хранятся в `source` внутри backend-модели и отбрасываются `toPublicVehicle()`.

## Пилотный просмотр без backend

Для проверки на статическом GitHub Pages добавлен очищенный публичный snapshot:

`collector/data/pilot-public-catalog.json`

Он не содержит provider name, source URL, dealer ID или listing ID.

Пилот включается query-параметром:

`cars.html?pilot=1`

Страница показывает реальную карточку и передаёт выбранный `vehicle_id` в `vehicle.html` через публичный объект в `sessionStorage`.

## Ограничение

Этот механизм предназначен для технической проверки одного автомобиля и согласования будущей партнёрской интеграции. Production Catalog Collector должен получать inventory через разрешённый feed/API или прямую выгрузку продавца. После получения такого доступа HTML pilot adapter можно оставить только как диагностический инструмент.

## Следующий критерий готовности

Проверить одну и ту же карточку повторно и зафиксировать изменения:

`active → price/mileage/photos update → last_seen_at → inactive при снятии с продажи`.

После этого следующий шаг — получить разрешённый inventory feed всего продавца и перевести импорт с одной URL-карточки на `DealerFeedProvider`.

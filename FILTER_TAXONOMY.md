# Авточек — справочник фильтров каталога

Дата проверки: 2026-08-19.

## Назначение

Фильтры публичного каталога используют собственную нормализованную терминологию Авточек. Названия и ссылки исходных площадок в пользовательский интерфейс не выводятся.

Справочник составлен по текущей структуре фильтров китайских used-car каталогов, которые исследуются как потенциальные источники inventory: Autohome/Che168 и Dongchedi.

## Марки

В `collector/src/catalog-taxonomy.js` зафиксирован стартовый справочник актуальных марок, встречающихся в текущих каталогах. В интерфейсе используются латинские/международные названия. Для входящих китайских значений Collector содержит aliases, например:

- `奥迪` → `Audi`;
- `宝马` → `BMW`;
- `奔驰` → `Mercedes-Benz`;
- `比亚迪` → `BYD`;
- `吉利汽车` → `Geely`;
- `长安` → `Changan`;
- `奇瑞` → `Chery`;
- `特斯拉` → `Tesla`;
- `蔚来` → `NIO`;
- `小鹏` → `XPeng`;
- `理想` → `Li Auto`;
- `极氪` → `Zeekr`;
- `问界` → `AITO`;
- `小米汽车` → `Xiaomi`.

Новые марки из реального feed сохраняются и добавляются в facets автоматически, даже если их пока нет в стартовом справочнике.

## Кузов

Китайские площадки используют одновременно классы автомобиля и структуру кузова. Авточек сводит их к пользовательскому набору:

- Седан;
- Хэтчбек;
- Лифтбек;
- Универсал;
- SUV;
- Кроссовер;
- MPV;
- Купе / спорткар;
- Кабриолет;
- Пикап;
- Минивэн / фургон;
- Другое.

Примеры нормализации:

- `三厢` → `Седан`;
- `两厢` → `Хэтчбек`;
- `掀背` → `Лифтбек`;
- `旅行版` → `Универсал`;
- `跨界车` → `Кроссовер`;
- `跑车` → `Купе / спорткар`;
- `皮卡` → `Пикап`.

## Тип силовой установки

Dongchedi разделяет бензин, дизель, обычный гибрид и new-energy подтипы: pure electric, range extender и plug-in hybrid. В отдельных фильтрах также встречается 48V mild hybrid. Autohome дополнительно показывает natural gas и methanol.

Авточек использует:

- Бензин;
- Дизель;
- Гибрид (HEV);
- Подключаемый гибрид (PHEV);
- Электро;
- Гибрид с увеличителем запаса хода (EREV);
- Мягкий гибрид 48V;
- Газ;
- Метанол;
- Прочее.

В `VehiclePublicDTO` для этого используется поле `energyType`. Поле `engine` остаётся для фактического двигателя/объёма/обозначения, например `2.0T`.

## Поведение фильтров

1. `cars.html` содержит стартовые варианты марок, кузовов и силовых установок, поэтому фильтры заполнены даже до подключения live API.
2. `/api/vehicles/facets` объединяет стартовый справочник с фактическими значениями текущего inventory.
3. Collector нормализует известные китайские значения в публичные значения Авточек.
4. Незнакомое значение марки или кузова сохраняется как есть и появляется через facets.
5. Неизвестный тип силовой установки попадает в `Прочее` до добавления alias.

## Следующий шаг после первого feed

После получения первого реального inventory нужно выгрузить все уникальные значения `brand`, `body`, `energy_type` и расширить aliases по фактическим данным партнёра. Это позволит убрать расхождения в написании и поддерживать единый фильтр при нескольких источниках.

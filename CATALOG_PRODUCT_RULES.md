# Авточек — правила публичного каталога

## Публичный интерфейс

Пользователь взаимодействует только с Авточек.

В карточках автомобилей на сайте показываются только нормализованные данные Авточек: фотографии, марка и модель, год, пробег, город, цена, характеристики, статус доступности и кнопка `Запросить отчёт`.

В публичном каталоге и карточке автомобиля не показываются:
- название площадки, с которой получено предложение;
- логотип площадки;
- внешняя ссылка на исходную карточку;
- интерфейс исходной площадки;
- технические идентификаторы интеграции.

## Внутренняя модель

Связь с исходным предложением хранится только на backend:

`vehicle_id → source_id → source_listing_id → source_url → source_account/workflow`

Публичный frontend получает нормализованный объект автомобиля без технических данных интеграции.

## Заказ отчёта

Пользователь открывает карточку автомобиля на Авточек и нажимает `Запросить отчёт`.

Дальнейшая цепочка:

`vehicle_id → проверка доступности отчёта → цена → оплата клиента → подтверждение оплаты → получение исходного отчёта → перевод → парсинг → нормализация → итоговый отчёт Авточек`.

Платная операция на стороне источника запускается только после подтверждённой оплаты клиента.

## Отчёт

В готовом отчёте может быть указано, где автомобиль был выставлен на продажу, если это нужно для происхождения данных и доверия. Это часть результата проверки и не является внешней навигацией или интерфейсом площадки.

## Текущий frontend

До подключения живого каталога используются только явно помеченные демонстрационные карточки. Реальные предложения и фотографии должны приходить через backend API Авточек.
